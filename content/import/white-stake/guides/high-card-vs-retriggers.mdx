## General Notes

With base hand size, retrigger set up comes out stronger, but with extra hand size, high card set up is better<br />
Each extra hand size with red seals gives about 1e (2 jokers), 2es (3-4 jokers), 3 es (5 jokers)<br />
Or for no red seal: 0.5e (2 jokers), 1e (3-4 jokers), 2es (5 jokers)

B = Baron<br />
M = Mime<br />
A = Ancient<br />
I = Idol<br />
D = Dusk
