Every card slot in the shop rolls one random number, and that number decides what the slot becomes: a Joker, Tarot, Planet, playing card or Spectral. Each type owns part of the roll, so a voucher that makes one type more likely takes its share from all the others.

## How it works

Every slot's roll is split into bands in a fixed order: Joker, Tarot, Planet, playing card, Spectral. Each band is as wide as its type's rate, out of the total of all rates:

| | Joker | Tarot | Planet | Playing card | Spectral |
| --- | --- | --- | --- | --- | --- |
| Base | 20 | 4 | 4 | 0 | 0 |
| Merchant | | 9.6 | 9.6 | | |
| Tycoon | | 32 | 32 | | |
| Magic Trick | | | | 4 | |
| Ghost Deck | | | | | 2 |

A Tycoon replaces its Merchant's rate instead of adding to it. A new voucher only changes cards that appear after you buy it: rerolls and the next shop, not what's already on the shelf.

Tags that put a free Joker in the shop (like the Uncommon and Rare Tags) fill that slot before the roll, so it always gets that Joker. Booster packs and vouchers have their own slots and don't use these odds.
